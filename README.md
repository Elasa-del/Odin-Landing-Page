# Tujube Restaurant — Landing Page

A responsive landing page built for **Tujube Restaurant**, celebrating authentic Ethiopian and Oromo cuisine. This project was created as part of **The Odin Project's Foundations** curriculum to practice modern web layout techniques using semantic HTML5 and CSS3 Flexbox.

## Live Demo

## 🔗 \*\*[View Live Site](https://elasa-del.github.io/Odin-Landing-Page/)

## Features & Sections

- **Navigation Header:** Features the custom Tujube Restaurant logo alongside quick navigation links (`Our Menu`, `Our Story`, `Contact & Location`).
- **Hero Section:** Introduces the restaurant with bold typography, a welcoming brand message, a primary call-to-action button, and a traditional Ethiopian platter showcase.
- **Signature Dishes Grid:** Highlights four traditional delicacies using flexible card layouts:
  - **Special Tibs** — Sautéed beef or lamb cubes with onions, rosemary, and green chili.
  - **Traditional Kitfo** — Minced lean beef seasoned with _niter kibbeh_ and _mitmita_, served with _ayib_ and _gomen_.
  - **Classic Doro Wat** — Slow-simmered spicy chicken stew served with a boiled egg on injera.
  - **Authentic Anchote** — Traditional Oromo root dish prepared with spiced butter and _ayib_.
- **Customer Testimonial:** A full-width quote banner featuring customer feedback.
- **Call-to-Action (CTA) Banner:** Prompts visitors to book a table or place an order online.

- **HTML5:** Semantic structure (`<header>`, `<nav>`, `<section>`, `<footer>`)

## How to Run Locally

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project directory:
   ```bash
   cd Odin-Landing-Page
   ```
3. Open `index.html` in your preferred web browser.
